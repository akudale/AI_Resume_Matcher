# Phonics sound clips

The 40 clips in this folder were generated by `tools/make_sounds.py`:

- Voice: **Kokoro-82M** (voice `af_heart`), Apache-2.0 — https://huggingface.co/hexgrad/Kokoro-82M
  (ONNX export: https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX)
- Checked with: **wav2vec2-lv-60-espeak-cv-ft** phoneme recogniser, Apache-2.0 —
  https://huggingface.co/facebook/wav2vec2-lv-60-espeak-cv-ft

Each consonant clip was cut from the start or end of a short word and kept only when the recogniser
heard exactly that sound. Each vowel was cut from a word like "cat", where it is the only voiced part,
after the whole word was heard correctly. `report.json` lists the source word and what was heard.

The clips are computer-made. Replace any file with a human recording of the same name and run
`python build_sounds.py`.
